An AI training coach that senses your recovery and tells you how to train today.

The three forms

Observe · Reason · Report

Like the three forms of Haki, hakigains does three things well — and nothing it shouldn't. It observes, it reasons, it reports. It never acts on your accounts.

Kenbunshoku · Observation

Observe

Pulls sleep, HRV, resting HR, Body Battery, stress and training load from Garmin, and folds indoor/outdoor variants into clean modality buckets.

ingest → readiness summary
Haoshoku · Judgement

Reason

One LLM call weighs recovery against load and your profile, then reconciles its call with Garmin's own readiness score — a second opinion, not a rubber stamp.

reason → session + rationale
Den Den Mushi · Transmit

Report

Delivers one specific session to your phone over Telegram — with a gated bot you can ask "why?", or re-tune on the spot.

deliver → Telegram
7-day readiness trend Garmin second opinion Modality normalization Goal-tied new suggestions Config-owned profile Live /set knobs Gated Telegram bot

Architecture

One core, two entry points

The same gated logic runs the scheduled cron and the live bot, so neither can accidentally skip the security gate.

EventBridge (daily)  ─►  ingest ─► reason ─► deliver → Telegram
Telegram webhook     ─►  bot/core (chat-ID gated) ─► /brief · /set · Q&A

secrets  AWS Secrets Manager — Garmin creds · LLM key · bot token
state    S3 — Garmin auth token + settings, synced across cold starts
brain    LLM behind a provider interface — Azure OpenAI today, Bedrock/Claude next
deploy   AWS SAM · container-image Lambda · ap-southeast-1

Captain's code

Your Garmin credentials stay on your own ship — there is no central service holding anyone's account. hakigains observes, reasons, and reports; it never sets sail with your keys. Self-host it, read every line, change the coaching in a file you own.
